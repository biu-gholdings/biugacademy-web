# Data privacy position

## Status

Privacy practices are **being defined** alongside intake and cohort systems. This document states directional commitments for public transparency.

## Principles

| Principle          | Commitment                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------ |
| Minimization       | Collect only data needed for stated educational purposes                                   |
| Purpose limitation | Use applicant data for admissions and program delivery, not unrelated sale                 |
| Security           | No secrets in git; protect production systems when deployed                                |
| Transparency       | Update this document when production intake storage goes live                              |
| Rights respect     | Provide contact channel for correction and deletion requests where applicable law requires |

## Data categories (illustrative)

- Contact information voluntarily provided
- Application responses (motivation, availability, track interest)
- Operational logs (non-PII where possible)

We avoid collecting national ID numbers or payment credentials in public forms unless legally required and explicitly justified.

## Children

If minors may apply in future programs, additional guardian consent and safeguards will be defined before launch.
