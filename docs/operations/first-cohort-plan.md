# First cohort plan

## Status

The first cohort is **planned**, not yet completed. This document defines the operating concept.

## Cohort concept

| Attribute     | Plan                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------- |
| Size          | Limited initial cohort (public site references a cap; exact number subject to operational confirmation) |
| Selection     | Application-based review                                                                                |
| Geography     | Priority for Angola-based candidates                                                                    |
| Primary track | Practical financial literacy                                                                            |
| Delivery      | Progressive; offline-first design goals                                                                 |

## Phased learning expansion

1. **First cohort** — Financial literacy core
2. **Later cohorts / modules** — Digital skills, AI readiness, entrepreneurship, technical pathways

## Success criteria (draft)

- Participants complete foundational financial literacy modules
- Measurable self-reported confidence and habit changes (instruments to be defined)
- Operational learnings captured for cohort 2 planning

## What we are not promising

- Jobs, loans, or investment returns
- Accredited degrees
- Automatic admission for all applicants
