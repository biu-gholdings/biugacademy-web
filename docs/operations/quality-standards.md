# Quality standards

## Purpose

Define how BIU.G Academy maintains educational and documentation quality as programs scale.

## Content quality

| Standard      | Requirement                                                                      |
| ------------- | -------------------------------------------------------------------------------- |
| Accuracy      | Facts verifiable; regulatory language reviewed                                   |
| Practicality  | Actionable steps; Angola-relevant examples                                       |
| Clarity       | Plain language; defined terms                                                    |
| Accessibility | Readable structure; see [../design/accessibility.md](../design/accessibility.md) |
| Versioning    | Material changes logged in [../../CHANGELOG.md](../../CHANGELOG.md)              |

## Review process (planned)

1. Author draft (PT-first)
2. Peer review (educator or subject reviewer)
3. Regulatory language check for public claims
4. Publish to approved channel

## Facilitation standards (planned)

- Prepared session guides
- Respectful participant interaction per [../../CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)
- No financial product sales during instruction unless formally disclosed and compliant

## Metrics (under design)

- Completion rates
- Participant feedback
- Content revision cycles
