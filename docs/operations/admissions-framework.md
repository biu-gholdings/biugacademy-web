# Admissions framework

## Status

Admissions processes are **under development** for the first cohort.

## Principles

| Principle | Description |
|-----------|-------------|
| Fairness | Consistent criteria applied by reviewers |
| Transparency | Public description of process; no hidden guarantees |
| Capacity | Admissions limited by facilitator and infrastructure readiness |
| Privacy | Minimal data collection |
| Integrity | No paid “guaranteed admission” schemes |

## Application flow (current / near-term)

1. Applicant visits cohort intake page (`/pt/entrar-primeira-turma/` or alias)
2. Applicant submits required fields
3. Confirmation page displayed (`candidatura-recebida` / thank-you)
4. Manual review by maintainers
5. Selection communication to accepted and waitlisted applicants

## Appeals

A simple appeal or clarification channel via [support@biugacademy.org](mailto:support@biugacademy.org) will be documented before cohort launch.
