# Transparency policy

BIU.G Academy commits to **honest public communication** as infrastructure matures. This policy describes aspirations and current practice—not a guarantee of funding levels or program scale.

**Status:** Policy **under development**; core documentation practices are **operational**.

---

## Reporting commitments

| Report                              | Cadence                               | Status          |
| ----------------------------------- | ------------------------------------- | --------------- |
| Roadmap and changelog               | On material change                    | **Operational** |
| Architecture and regulatory docs    | Versioned in git                      | **Operational** |
| Annual public summary               | Yearly when programs operate at scale | **Planned**     |
| Cohort outcomes summary             | After first completed cohort          | **Planned**     |
| Donation / sponsorship use of funds | If fundraising activates              | **Planned**     |

---

## Donation handling philosophy (planned)

When donations or sponsorships are accepted:

- Purpose-limited use (scholarships, content, facilitation)
- No pay-to-win admissions
- Sponsors do not control curriculum accuracy or regulatory statements
- Public summary of aggregated funds and uses (without donor PII)

No fundraising mechanism is claimed as operational in this repository today.

---

## Educational integrity

- Programs described as **under development** until delivered
- No misrepresentation of degrees, licenses, or government relationships
- Facilitators and contributors must follow [../../CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)
- Corrections published when material errors are identified

---

## No guaranteed outcomes disclaimer

BIU.G Academy does **not** guarantee:

- Employment or income
- Loan approval or credit outcomes
- Investment returns
- Admission to future cohorts
- Accredited degrees (not offered today)

---

## Responsible communication standards

| Standard              | Application                                              |
| --------------------- | -------------------------------------------------------- |
| Evidence-based claims | Match [../../README.md](../../README.md) status tables   |
| Partnerships          | Public only with executed agreements                     |
| Statistics            | Cite official sources; avoid unverified national figures |
| AI                    | Describe as assistive and planned until deployed         |
| Photography / stories | Consent-based when learner stories are used (future)     |
