# Digital skills track

## Status

**Planned expansion** after the first cohort financial literacy foundation.

## Learning objectives (planned)

- Basic device and internet safety literacy
- Productivity tools for work and learning
- Communication professionalism (email, messaging norms)
- Introduction to digital income pathways (without income guarantees)

## Design constraints

- Lessons must work on common smartphones
- Offline-first packaging where downloads are feasible
- No requirement for expensive hardware
