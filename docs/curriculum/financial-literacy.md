# Financial literacy track

## Status

**Primary focus for the first planned cohort.** Content is under development.

## Learning objectives (planned)

Learners should be able to:

- Build and maintain a simple personal or household budget
- Understand debt, interest, and repayment discipline
- Establish consistent savings habits appropriate to local income volatility
- Plan income streams realistically (employment, informal work, small business)
- Apply basic financial discipline to micro-business cash flow

## Module themes (draft)

| Module | Topics |
|--------|--------|
| Foundations | Income, expenses, needs vs wants |
| Budgeting | Monthly planning, tracking, adjustment |
| Debt awareness | Responsible borrowing, avoidance of harmful cycles |
| Savings | Emergency funds, goal-based saving |
| Small business money | Simple cash flow for vendors and sole traders |

## Angola-first context

Examples use realistic Angolan scenarios—informal income, mobile money where relevant, and variable connectivity for lesson delivery.

## Outcomes language

We describe **skill development**, not guaranteed wealth or credit approval.
