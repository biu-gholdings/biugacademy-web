# Accessibility

## Goals

The static site should remain usable for learners on mobile devices, smaller screens, and assistive technologies where feasible without introducing heavy frameworks.

## Current practices

- Responsive layout and mobile navigation toggle
- Semantic HTML landmarks (`header`, `main`, `footer`, `nav`)
- `lang` attributes on localized pages (`pt-AO`, etc.)
- Alt text on logo images (may be refined for descriptive alts)
- Sufficient color contrast on primary text and buttons (review when changing tokens)

## Improvement backlog

- Audit all images for meaningful `alt` text
- Verify focus states for keyboard navigation
- Test form labels and error messages on intake pages
- Document PT/EN/FR accessibility parity

## Content accessibility

- Plain language per [content-style-guide.md](content-style-guide.md)
- Offline-first content packaging (future curriculum) for low-bandwidth users

## Feedback

Report accessibility barriers to [support@biugacademy.org](mailto:support@biugacademy.org).
