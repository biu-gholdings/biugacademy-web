# Partnership framework

How institutions **may** engage with BIU.G Academy in the future. **No partnership is active or implied** unless announced on the official website with a published agreement summary.

**Status:** Framework **under development**.

---

## Partnership types (illustrative)

| Type                          | Potential scope                                                             |
| ----------------------------- | --------------------------------------------------------------------------- |
| **NGO co-delivery**           | Community reach, facilitator support, shared metrics                        |
| **University extension**      | Non-degree workshops; formal accreditation only via separate lawful process |
| **Employer pipeline**         | Skills orientation; no employment guarantees                                |
| **Public literacy campaigns** | Aligned messaging with government programs only when formally authorized    |
| **Technology contributors**   | Open documentation, accessibility, translation                              |

---

## What BIU.G Academy offers (planned)

- Documented curriculum frameworks
- Angola-first, offline-first design constraints
- Transparent governance artifacts in this repository
- Cohort models subject to capacity

---

## What BIU.G Academy does not offer today

- Accredited degrees
- Government endorsement on behalf of partners
- Exclusive territorial franchises
- Revenue guarantees for partners

## Engagement process (planned)

1. Initial inquiry to [support@biugacademy.org](mailto:support@biugacademy.org)
2. Scope alignment and regulatory review
3. Executed MOU or agreement (legal counsel)
4. Public announcement only after signing

MOU template outline: **planned** (`mou-template-outline.md`).

---

## Integrity rules

- Partners must not misrepresent accreditation status
- Co-branded materials require brand review per [../branding/brand-guidelines.md](../branding/brand-guidelines.md)
- Data sharing requires privacy review
