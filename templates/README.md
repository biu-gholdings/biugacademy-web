# Institutional templates

This directory contains source templates for outward-facing institutional documents.

## Structure

- `whitepaper/` — strategic white paper templates
- `reports/` — annual, cohort, and curriculum report templates
- `partnerships/` — partnership and donor proposal templates
- `governance/` — governance report templates

## Standards

All templates follow:

- [docs/branding/document-system.md](../docs/branding/document-system.md)
- [docs/branding/brand-guidelines.md](../docs/branding/brand-guidelines.md)
- [docs/operations/pdf-export-pipeline.md](../docs/operations/pdf-export-pipeline.md)

## Notes

- Templates are markdown source files for PDF export.
- Apply document control and confidentiality labels before sharing externally.
